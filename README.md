# Генератор постов для соцсетей

Веб-панель, которая превращает сухие данные о товаре в готовый продающий пост. Вы заполняете название,
описание и цену, выбираете тональность — нейросеть пишет текст, который можно поправить руками и сразу
опубликовать в сообществе ВКонтакте.

Генерация идёт через **DeepSeek** (модель `deepseek/deepseek-chat`) по OpenAI-совместимому API ProxyAPI,
то есть с оплатой в рублях и без VPN.

## Что умеет

- генерирует пост по трём полям: название товара, описание, цена;
- поддерживает 6 тональностей (Tone of Voice): экспертный, дружелюбный, юмористический, продающий,
  официально-деловой и сторителлинг;
- если ИИ недоступен (нет ключа, кончился баланс, пропала сеть) — включает резервный локальный
  генератор: он собирает текст по шаблонам для выбранной тональности, чтобы панель не оставалась пустой;
- показывает понятные всплывающие уведомления об успехе и об ошибках;
- публикует готовый текст на стену сообщества ВКонтакте от имени сообщества;
- сохраняет выбранную тональность в файл `voice.md`, чтобы она не терялась между запусками;
- текст в поле можно свободно редактировать перед публикацией — в VK уйдёт именно то, что в поле.

## Технологии

| Компонент | Что используется |
|---|---|
| Бэкенд | Python + Flask 3 |
| Шаблоны | Jinja2 (входит в Flask) |
| Интерфейс | Bootstrap 5 (подключается с CDN) + встроенные стили в шаблоне |
| Запросы к API | `requests` |
| Нейросеть | DeepSeek `deepseek/deepseek-chat` |
| Шлюз к модели | ProxyAPI — https://proxyapi.ru |
| Публикация | VK API, метод `wall.post` |
| Конфигурация | `python-dotenv` |

## Установка и запуск

1. **Создайте виртуальное окружение и активируйте его**

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   В Linux/macOS: `python3 -m venv .venv && source .venv/bin/activate`

2. **Установите зависимости**

   ```powershell
   pip install -r requirements.txt
   ```

3. **Создайте файл `.env` из примера**

   ```powershell
   Copy-Item .env.example .env
   ```

4. **Заполните переменные в `.env`**

   | Переменная | Что указать |
   |---|---|
   | `SECRET_KEY` | Секретный ключ Flask. Сгенерируйте командой `python -c "import secrets; print(secrets.token_hex(32))"` |
   | `OPENAI_API_KEY` | Ключ ProxyAPI из личного кабинета https://proxyapi.ru |
   | `OPENAI_BASE_URL` | `https://api.proxyapi.ru/v1` |
   | `OPENAI_MODEL` | `deepseek/deepseek-chat` |
   | `VK_TOKEN` | Токен доступа ВКонтакте с правом `wall` |
   | `VK_GROUP_ID` | ID сообщества, например `-240202409` (у сообществ ID отрицательный) |

5. **Запустите панель**

   ```powershell
   python app.py
   ```

   Откройте http://127.0.0.1:5000. Сервер работает в режиме отладки (`debug=True`). Остановить — `Ctrl+C`.

## Как это работает

На странице три действия, каждое — отдельная кнопка формы:

| Кнопка | Что происходит в коде |
|---|---|
| 🤖 Сгенерировать пост через ИИ | Собирается промпт из полей товара и тональности, уходит `POST` на `{OPENAI_BASE_URL}/chat/completions`, ответ модели подставляется в поле текста |
| 📝 Зафиксировать в voice.md | Выбранная тональность записывается в файл `voice.md` |
| 🚀 Опубликовать в VK | Текст отправляется в VK методом `wall.post` с параметром `from_group=1` |

Промпт к модели включает системную роль («Ты опытный SMM-копирайтер…»), температуру `0.7`, лимит
`800` токенов и таймаут 60 секунд. Если запрос не удался, в интерфейсе появится уведомление, а текст
соберётся резервным шаблонным генератором — в конце такого текста будет пометка
`🤖 [Сгенерировано в режиме Friendly-Вайбкодинга!]`.

### Про публикацию в VK

Метод `wall.post` возвращает HTTP-код `200` даже при ошибке, поэтому результат разбирается по JSON:
если в ответе есть блок `error`, в интерфейсе показывается причина от VK (например,
`Access denied: no access to call this method`), а не ложное «успешно опубликовано».

Чтобы публикация прошла, нужны две вещи: у токена `VK_TOKEN` должно быть право `wall`, а пользователь,
которому принадлежит токен, должен быть администратором сообщества `VK_GROUP_ID`.

## Структура проекта

```
post_generator/
├── app.py                  # всё приложение: конфиг, генерация через ProxyAPI, публикация в VK
├── requirements.txt        # зависимости Python
├── voice.md                # сохранённая настройка Tone of Voice
├── .env.example            # шаблон переменных окружения (можно публиковать)
├── .env                    # ваши реальные ключи и токены (в Git не попадает)
├── .gitignore              # исключает .env и служебные файлы
├── static/
│   └── style.css           # остался от ранней версии; сейчас не подключён — оформление идёт через Bootstrap
└── templates/
    └── index.html          # форма, выбор тональности, поле текста и кнопки действий
```

## Безопасность

`SECRET_KEY`, токен ВКонтакте и ключ ProxyAPI читаются из переменных окружения и не хранятся в коде.
Файл `.env` внесён в `.gitignore` — в репозиторий попадает только `.env.example` с пустыми значениями.
